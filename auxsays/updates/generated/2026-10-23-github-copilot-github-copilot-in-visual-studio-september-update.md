  \ use the models your team prefers, through GitHub Copilot or your own model deployments, whether or not you’re signed in\
  \ to GitHub. This feature is on by default across the Community, Professional, and Enterprise editions. Breaking change:\
  \ BYOM now requires the new Agent (Preview), built on the GitHub Copilot SDK-powered harness. The previous Ask and Agent\
  \ modes no longer support BYOM, and you’ll need to re-add previously configured Ollama models after updating. Supported\
  \ providers include Microsoft Foundry, OpenAI, Anthropic, and Ollama.\n Fix NuGet Vulnerabilities from the Error List :\
  \ NuGet Audit warnings in the Error List now include a fixer action that opens GitHub Copilot Chat in agent mode and asks\
  \ Copilot to fix the vulnerable packages using the NuGet MCP server. This functionality requires signing in to GitHub Copilot\
  \ and enabling the NuGet MCP server from the Copilot Chat tools menu.\n\n This update is available to users on all GitHub\
  \ Copilot plans , including Copilot Free, Student, Pro, Pro+, Max, Business, and Enterprise.\n\n\n Download Visual Studio\
