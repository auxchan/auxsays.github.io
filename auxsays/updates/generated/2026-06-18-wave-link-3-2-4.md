  Wave devices would not appear in Wave Link depending on the Windows region format setting. Fixed an issue where audio playback
  through Wave XLR Pro outputs would stop when Wave Link was closed. Fixed an issue where audio applications could stop routing
  through Wave Link after waking from sleep, showing as "Unavailable" despite actively playing audio. Fixed an issue where
  users with Wave XLR Pro could be limited to fewer than 8 channels. Fixed an issue where the input gain of Wave XLR MK1 would

  active mixer transition. Fixed an issue where Wave XLR Pro hardware outputs were missing from the Personal Mix output assignment

  to a Wave XLR Pro output did not take effect while Sound Check was already playing. Fixed an issue where the Expander toggle
