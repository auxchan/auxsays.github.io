release_summary: "The HydraFusion research preview is now available in Visual Studio Code and the GitHub Copilot app, expanding\
  \ beyond Copilot CLI.\n\n\n HydraFusion appears in the model picker, but rather than being a single model, it orchestrates\
  \ multiple models. HydraFusion treats workflow selection as an optimization problem. It uses capability signals for reasoning,\
  \ code generation, debugging, and tool use to select the most efficient execution pattern to meet the quality bar. HydraFusion\
  \ uses one of three workflows:\n\n\n\n Single: One selected model directly solves the task.\n Cascade: An efficient model\
  \ drafts a solution and a quality gate decides whether to accept it or escalate to a stronger model.\n Critique: One model\
  \ drafts a result, an independent read-only critic from a different model family reviews it—following the same review pattern\
  \ as Rubber Duck —and the drafting model revises once.\n\n Get started\n In VS Code (version 1.140 or later, or VS Code\
  \ Insiders):\n\n\n\n Select HydraFusion from the Copilot Chat model picker.\n If it does not appear, enable chat.copilot.hydraFusion.enabled\
  \ . If you get Copilot through an organization or enterprise, an administrator may need to allow preview features in organization\
  \ or enterprise settings.\n\n In the GitHub Copilot app:\n\n\n\n Update to the latest version.\n Open Settings , search\
  \ for “HydraFusion”, and turn it on.\n Select HydraFusion from the model picker.\n\n What’s improved\n Bringing HydraFusion\
  \ to more surfaces was the top request from early feedback. This release also improves the overall experience:\n\n\n\n Greater\
  \ transparency: See more clearly what HydraFusion is doing at each step of a workflow.\n Real-time progress: HydraFusion\
  \ now sends more frequent progress updates while it works.\n Clearer status during long tasks: Progress updates make it\
  \ easier to tell that HydraFusion is still working, even when a task takes longer.\n\n How HydraFusion differs from Auto\n\
  \ Auto selects a model for each request. HydraFusion explores how Copilot can both select a workflow and coordinate multiple\
  \ models within a turn.\n\n\n HydraFusion is available to Copilot Pro, Pro+, Business, and Enterprise users. For Copilot\
  \ Business and Enterprise, an administrator must enable preview features. HydraFusion remains a research preview and is\
  \ subject to change.\n\n\n Learn more in the HydraFusion documentation , read about the research and benchmark results in\
  \ Project HydraFusion: Frontier quality via multi-model orchestration , or share feedback in the GitHub Community .\n\n\n\
  \n The post HydraFusion in VS Code and the GitHub Copilot app appeared first on The GitHub Blog ."
