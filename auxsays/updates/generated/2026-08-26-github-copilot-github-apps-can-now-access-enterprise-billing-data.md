release_summary: "Enterprise owners can now grant a GitHub App access to enterprise billing data. When you create or configure\
  \ a GitHub App, you can select the enterprise billing permission and choose one of two levels: read or read and write.\n\
  \n\n Previously, the only way to read usage or manage budgets and cost centers through the API was a personal access token\
  \ belonging to an enterprise owner or billing manager. That tied your billing automation to one person’s token, so it broke\
  \ when that person changed roles or left.\n\n\n Now an app installation access token that carries the enterprise billing\
  \ permission can call the enterprise billing REST API endpoints. Use it to pull usage data into your finance and BI systems,\
  \ reconcile invoices, and manage budgets and cost centers, all without relying on an individual’s token. As an added benefit,\
  \ you also get higher rate limits than a personal access token.\n\n\n The enterprise billing permission is available on\
