  \ protection rules . In the Review import dialog, you can:\n\n\n\n Preview the rulesets that will be created before you\
  \ confirm the conversion.\n See which branch protection rules are already covered by an existing ruleset.\n Review cases\
  \ where one branch protection rule produces multiple rulesets to preserve its original behavior.\n Choose an enforcement\
  \ status (e.g., Active , Evaluate , or Disabled ) and select which rulesets to create.\n\n After you click Create rulesets\
  \ , choose whether to keep or delete the original branch protection rules.\n\n\n Why migrate to rulesets?\n Rulesets offer\
  \ several advantages over classic branch protections:\n\n\n\n Apply rules across multiple branches with pattern matching\n\
