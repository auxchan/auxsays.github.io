release_summary: "Claude Fable 5.2, Anthropic’s newest Fable model, is now generally available in GitHub Copilot. You can\
  \ use it for complex, multistep coding tasks across large codebases. In early testing, Fable 5.2 solved more tasks than\
  \ Claude Fable 5.1 while using fewer steps and tool calls. It also completed hard tasks that earlier models missed.\n\n\n\
  \ Claude Fable 5.2 requires data retention by default to operate Anthropic’s safety classifiers. Zero data retention access\
  \ is available for certain eligible enterprise customers. Continue reading for more details.\n\n\n This model is billed\
  \ at provider list pricing under usage-based billing. See Models and pricing for GitHub Copilot for details.\n\n\n Availability\
  \ in GitHub Copilot\n Claude Fable 5.2 is available to Copilot Pro+, Max, Business, and Enterprise users. You can select\
  \ the model in the model picker in:\n\n\n\n Visual Studio Code\n Visual Studio\n Copilot CLI\n GitHub Copilot coding agent\n\
  \ GitHub Copilot app\n github.com\n GitHub Mobile on iOS and Android\n JetBrains IDEs\n Xcode\n Eclipse\n\n Rollout will\
  \ be gradual. Check back soon if you don’t see it yet.\n\n\n Enabling access\n Copilot Enterprise and Copilot Business plan\
  \ administrators must enable the Claude Fable 5.2 policy in Copilot settings. The policy is off by default.\n\n\n Claude\
  \ Fable 5.2 requires data retention by default. When Claude Fable 5.2 is used, Anthropic retains data, including prompts\
  \ and outputs, to operate safety classifiers that detect harmful use. Retained data is not used to train Anthropic’s models.\
  \ Other Claude models, except for Fable 5, Fable 5.1, and Fable 5.2, continue to operate under zero data retention (ZDR).\n\
  \n\n To learn more, see Anthropic’s data retention practices for Mythos-class models . Enabling the Claude Fable 5.2 policy\
  \ constitutes acknowledgment of this requirement. Leaving it off keeps Claude Fable 5.2 unavailable to your organization.\n\
  \n\n Zero data retention access for eligible enterprises\n Eligible customers can use Claude Fable 5.2, Claude Fable 5.1,\
  \ and Claude Fable 5 with zero data retention through the end of the calendar year under a time-bound exemption while Anthropic\
  \ rolls out Enterprise Frontier Safeguards (EFS). After that point, continued use of the models will require EFS, which\
  \ will enable automated safety monitoring while also giving eligible customers more options for how their data is retained.\
  \ This includes the option to use storage and encryption keys under their own control. Between now and then we will be working\
  \ with Anthropic to provide feedback on EFS.\n\n\n If your enterprise is approved for access, Claude Fable 5.2, Fable 5.1,\
  \ and Fable 5 requests will be routed to zero data retention endpoints when the model is enabled. To learn whether your\
  \ organization qualifies, contact your GitHub account team. GitHub Support cannot determine eligibility or enable access.\n\
  \n\n Approval will not automatically enable the models. After approval, a Copilot Enterprise or Copilot Business administrator\
  \ must still enable the Claude Fable 5.2 policy in Copilot settings.\n\n\n Learn more\n To explore all models available\
  \ in GitHub Copilot, see our documentation on models and get started with Copilot.\n\n\n Share your feedback\n Join the\
  \ GitHub Community to share your feedback.\n\n\n\n The post Claude Fable 5.2 in GitHub Copilot appeared first on The GitHub\
  \ Blog ."
