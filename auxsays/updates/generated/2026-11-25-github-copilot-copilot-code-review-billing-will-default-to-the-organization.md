release_summary: "If you haven’t chosen how to bill Copilot code review for members with a Copilot license, those reviews\
  \ will be billed to your organization starting December 30, 2026. To keep billing unchanged, select Member before then.\
  \ This change applies to organizations and enterprises with Copilot Business or Copilot Enterprise.\n\n\n What’s changing\n\
  \ Today, when no billing choice is saved, reviews by members who have a paid Copilot license use the member’s Copilot entitlement.\
  \ Starting December 30, 2026, those reviews will be billed to the organization that owns the repository. Accounts that don’t\
  \ have AI Credits paid usage enabled, have a billing lock, or have no billable customer will be set to Member instead.\n\
  \n\n\n If you already chose Member or Organization , your choice stays in effect.\n The separate setting for members without\
  \ a Copilot license doesn’t change.\n\n Keep member billing\n Until then, unset settings show Default (Member) with a notice\
  \ about the change. To keep using members’ Copilot entitlements, select Member in your enterprise or organization Copilot\
  \ policy settings. That choice stays in effect after the default changes.\n\n\n If your enterprise manages this setting,\
  \ an enterprise owner makes this choice.\n\n\n Organization billing requires AI Credits paid usage and can increase your\
  \ organization’s spending.\n\n\n To learn more, see Configuring code review by GitHub Copilot .\n\n\n\n The post Copilot\
  \ code review billing will default to the organization appeared first on The GitHub Blog ."
