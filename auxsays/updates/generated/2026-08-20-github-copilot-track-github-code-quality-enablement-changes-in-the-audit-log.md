release_summary: "GitHub Code Quality now writes an audit log event whenever someone enables, disables, or changes its settings\
  \ on a repository. Three new events give you that history:\n\n\n\n repo.code_quality_enabled records when someone turns\
  \ on Code Quality for a repository.\n repo.code_quality_disabled records when someone turns it off.\n repo.code_quality_updated\
  \ records when someone changes the configuration of a repository that already has Code Quality enabled.\n\n Each event captures\
  \ the repository, the actor who made the change, and when it happened. Because Code Quality billing counts active committers\
  \ on enabled repositories, you can now see exactly when a repository entered or left that scope.\n\n\n You’ll find these\
  \ events in your organization audit log and enterprise audit log , and you can query them with the audit log API.\n\n\n\
