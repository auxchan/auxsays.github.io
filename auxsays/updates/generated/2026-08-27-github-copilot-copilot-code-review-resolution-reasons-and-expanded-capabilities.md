  \ cloud agent pull requests\n Previously, when Copilot code review was automatically requested due to automatic review settings\
  \ on pull requests authored by Copilot cloud agent, Copilot code review would fall back to a limited experience. Copilot\
  \ code review can now give pull requests opened by Copilot cloud agent a full agentic review.\n\n\n Large pull requests\n\
  \ Copilot code review previously had a 300 file or 20,000 lines of code limit on the size of a pull request it could review.\
  \ This limitation no longer applies.\n\n\n ☑️ Comment resolution reasons\n You can now specify the reason for resolving\
  \ a Copilot code review comment by either selecting “Addressed”, “Won’t fix”, or “Incorrect”, after clicking the new dropdown\
  \ next to the “Resolve conversation” button, located at the bottom of any Copilot code review comment. Selecting one of\
  \ these options provides valuable feedback to the product team and helps improve the product.\n\n\n\n\n\n\n The post Copilot\
