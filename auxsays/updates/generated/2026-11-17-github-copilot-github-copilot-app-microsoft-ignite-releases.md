release_summary: "Copilot is most useful when it can work where you do. The GitHub Copilot app now supports your Azure DevOps\
  \ repositories, your GitHub Enterprise Server instance, and the browser you’re already signed in to.\n\n\n Work with Azure\
  \ DevOps repositories in the GitHub Copilot app\n Clone an Azure DevOps repository, ask an agent to create a branch, make\
  \ code changes, and open a pull request, then see it through to completion without leaving the GitHub Copilot app. Track\
  \ its status in the sidebar, click Fix on a review comment to have an agent address it, or turn on agent merge to let an\
  \ agent fix CI failures and complete the pull request once your Azure DevOps checks and policies pass.\n\n\n Azure DevOps\
  \ integration is now in public preview. To get started, open Settings > Experimental and turn on Azure DevOps integration\
  \ , then go to Accounts > Add account and sign in with the Microsoft account you use for Azure DevOps. Cloud sessions aren’t\
  \ available for Azure DevOps repositories.\n\n\n For more information, see the Azure DevOps documentation .\n\n\n\n\n\n\n\
  \n Let Copilot work in your browser\n Ask Copilot to fill out forms, pull information from webpages, or test and debug the\
  \ web app you’re building, right in the browser you’re already signed in to. Browser use, now in public preview, works in\
  \ Chromium-based browsers, including Google Chrome and Microsoft Edge, with the GitHub Copilot extension for Chrome and\
  \ runs in an isolated tab group. It also works alongside computer use.\n\n\n Browser use is off by default. To get started,\
  \ install the extension, then open Settings > Computer Use and turn on both Enable Computer Use and Enable Browser Use .\
  \ You can manage permission levels in the extension’s settings.\n\n\n\n\n\n Browser use is also available in Copilot CLI,\
  \ VS Code, and JetBrains IDEs.\n\n\n For more information, see the browser use documentation .\n\n\n Bring your GitHub Enterprise\
  \ Server work into the app\n Add your GitHub Enterprise Server (GHES) account to work with remote repositories, issues,\
  \ and pull requests in the GitHub Copilot app. GHES support, previously an opt-in preview, is now generally available. Update\
  \ to GitHub Copilot app version 1.2.0 or later to use it.\n\n\n To get started, sign in with a GitHub.com or GHE.com account,\
  \ then open Settings > Accounts > Add account and choose GitHub Enterprise Server . Cloud sessions aren’t available for\
  \ GHES.\n\n\n For more information, see the Copilot GHES documentation .\n\n\n Get started\n Download or update the GitHub\
  \ Copilot app .\n\n\n\n The post GitHub Copilot app, Microsoft Ignite releases appeared first on The GitHub Blog ."
