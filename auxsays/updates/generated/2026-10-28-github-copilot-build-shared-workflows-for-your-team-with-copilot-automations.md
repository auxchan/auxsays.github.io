release_summary: "Shared Copilot Automations are rolling out, enabling teams to build and maintain AI-powered workflows together.\n\
  \n\n With Copilot Automations, you can combine prompts, triggers, and tools to design workflows around the way your team\
  \ works. Copilot runs autonomously in the cloud, using only the tools you’ve allowed. For example, you could create automations\
  \ to:\n\n\n\n Reproduce bugs as soon as an issue is opened.\n Capture screenshots of the changes when a pull request is\
  \ marked as ready.\n Automatically investigate production incidents as soon as they’re detected in your monitoring tool.\n\
  \n Until now, automations have been personal, meaning only you could see and edit them, and they used your identity and\
  \ AI credits. That works well for automating your own work, like drafting your standup updates, but not for workflows your\
  \ whole team relies on. Shared automations let your team build and maintain those workflows together.\n\n\n How shared automations\
  \ work\n\n Visible to your team : Everyone with read access to the repository can see a shared automation, and anyone with\
  \ write access can edit it.\n Billed to the repository owner : AI credits are billed to the organization or user that owns\
  \ the repository, rather than to the person who created the automation.\n Act as Copilot : Actions on GitHub are attributed\
  \ to Copilot, rather than to any one user.\n Built to last : Shared automations belong to the repository, so they keep running\
  \ if the person who created them leaves the team. Change history lets your team see how the tools, triggers, and prompt\
  \ have evolved.\n\n For shared automations to run in an organization-owned repository, an administrator must enable the\
  \ “Allow use of Copilot cloud agent billed to the organization” policy.\n\n\n Create a shared automation\n When you create\
  \ an automation on github.com, the GitHub Copilot app , or Visual Studio Code, choose Shared under Type . You can’t change\
  \ an automation’s type after you create it. To learn more, see personal and shared automations .\n\n\n Shared Copilot Automations\
  \ are rolling out to users on Copilot Pro, Pro+, Max, Business, and Enterprise plans. Availability may vary as the rollout\
  \ progresses. Once available, you can create automations in any repository where you have write access.\n\n\n Join the discussion\
  \ within GitHub Community .\n\n\n\n The post Build shared workflows for your team with Copilot Automations appeared first\
  \ on The GitHub Blog ."
