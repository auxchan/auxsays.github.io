release_summary: "This week, bring GitHub Enterprise Server repositories into the Copilot app and see which agent sessions\
  \ need you first in VS Code. You can also try two new models, Claude Fable 5.2 and Gemini 4 Carbon.\n\n\n GitHub Copilot\n\
  \n Claude Fable 5.2 is available to Copilot Pro+, Max, Business, and Enterprise users. It requires data retention by default,\
  \ and Copilot Business and Enterprise administrators must turn on its policy, which is off by default. Learn more about\
  \ Claude Fable 5.2 .\n Gemini 4 Carbon is available to Copilot Pro+, Max, Business, and Enterprise users.\n\n GitHub Copilot\
  \ app\n\n Continue cloud and Codespace sessions on your phone. A new Open in menu includes a GitHub Mobile option that shows\
  \ a QR code.\n Sign back in to MCP servers such as Slack without leaving the conversation. When a server needs you to sign\
  \ in again, the conversation offers the matching connector, connects it in place, and resumes your task.\n Work with repositories,\
  \ issues, and pull requests from GitHub Enterprise Server in the Copilot app, now generally available. You’ll still need\
  \ a GitHub.com or GHE.com account, and cloud sessions aren’t available for GHES. Learn more about signing in with GHES .\n\
  \ Schedule Project automations down to the minute, or use a custom cron schedule such as weekdays at 9:30.\n Dictate in\
  \ French, Spanish, and other languages. Download the multilingual voice model in settings, then choose Auto or a specific\
  \ language.\n Filter issues and pull requests by custom fields, such as a GitHub Project’s Size, from the Add filter menu.\n\
  \ Combine high contrast with red, green, or blue-yellow color filters in Settings > Accessibility , and preview combinations\
  \ before you apply them. High contrast replaces the separate “Increase contrast” setting. You can also choose GitHub Dimmed\
  \ as a dark-only palette in Settings > Themes .\n\n Install the GitHub Copilot app .\n\n\n GitHub Copilot in VS Code (1.146\
  \ release)\n\n Let an agent run model comparisons for you. With Compare Models enabled, turn on the agent tools in settings,\
  \ and agents can find available models, launch comparisons, and read the results to summarize findings. This is experimental.\n\
  \ Track agent sessions across all your workspaces from one view with Inbox mode in the Agents window’s sessions list. Sessions\
  \ that need your attention appear first, and you can dismiss, hold, or snooze the rest. This is experimental.\n Move a chat\
  \ out of the Agents window into its own window, then arrange the chat, its editors, and its terminals to fit the task. Chat\
  \ windows are in preview.\n Find, install, and uninstall extensions without leaving the Agents window. Extensions with unsupported\
  \ features show a warning before you install them. This is experimental.\n Move to the Copilot harness before the Local\
  \ harness is removed in February 2027. The Copilot harness is already the default for new sessions, and the transition guide\
  \ covers moving any remaining workflows.\n\n Explore everything that’s new in the full release notes .\n\n\n\n The post\
  \ GitHub Copilot weekly releases — November 9 appeared first on The GitHub Blog ."
