  tame your voice. If the LEDs are excessively or consistently shining orange, try turning down Gain by a few decibels. Your
  viewers and Wave XLR will thank you. Learn how to update Wave XLR firmware. 🆕 Low Impedance Mode (Wave XLR) This update
  with the new firmware version 1.3 also adds Low Impedance Mode. This mode changes the impedance of the headphone output
  for use with IEM (in-ear monitors) or other sensitive headphones, which reduces unwanted noise. Learn how to update Wave
  XLR firmware. 🆕 Native Apple Silicon (M1) Support It feels snappier, right? With this update, Wave Link is a native Apple
