  OBS Studio. Captured audio would sometimes stutter or break. Not anymore! Learn how to update your HD60 X firmware here

  ↔️ EDID Improvements Overhauled EDID timing to better support 1440p120 with compatible passthrough displays. Improved handling
  of EDIDs containing DisplayID data blocks, which resolved an issue when using a Gigabyte M28U monitor for passthrough. Improved
  compatibility with Stream Deck by adding a new Stream Deck specific EDID. Learn more about using custom EDIDs. 🎞 Fractional
  fps filter for Smart Folders Harking back to the beginning of TV and broadcast, consoles will output 60fps video as 59.94
  Hz. Improved filters in the video library so that 30 / 60 fps also include 29.97 / 59.94 fps. Learn more about using Smart
  Folders. 🛠 Bug fixes and performance improvements: Fixed an issue where Cam Link 4K video was darker than expected when
  4K Capture Utility was open. Resolved a bug that could cause Live Commentary to be enabled unintentionally. Resolved a bug
  where recordings would fail or a message would incorrectly appear stating that a recording is already in progress when HDR
  recording was enabled.'
