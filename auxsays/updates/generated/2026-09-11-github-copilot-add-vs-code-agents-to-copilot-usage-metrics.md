  \ 1-day and 28-day periods now include:\n\n\n\n used_vscode_agent : An optional indicator of whether the user used the VS\

  \ this matters\n These metrics help you understand how many people use the VS Code Agents window and how they engage with\
  \ it. You can use the aggregate reports to track adoption and activity trends, then use the user-level reports to understand\
  \ usage across teams.\n\n\n Important notes\n\n These metrics cover the dedicated VS Code Agents window only. They remain\
  \ separate from editor-window Agent Mode and generic usage rollups.\n Missing-data behavior is backward compatible — optional\
  \ fields remain absent or null when corresponding VS Code Agents-window data is unavailable.\n Access is available to enterprise\
  \ owners and billing managers, organization owners, and anyone with a custom organization or enterprise role granting View\
  \ Copilot Metrics . The Copilot usage metrics policy must be enabled.\n\n Visit the Copilot usage metrics API documentation\
  \ to get started.\n\n\n\n The post Add VS Code Agents to Copilot usage metrics appeared first on The GitHub Blog ."
