release_summary: "This update brings more control over default models and MCP server in GitHub Copilot for JetBrains. It also\
  \ makes diagnostics easier to address, improves chat navigation and account controls, and strengthens reliability across\
  \ agent sessions, customizations, and worktrees.\n\n\n What’s new\n Enterprise-managed default models\n Enterprise administrators\
  \ can now use managed settings to choose any available Copilot agent model as the default for new conversations. This gives\
  \ organizations more control over the starting model while still preserving an explicit model picker choice.\n\n\n Faster\
  \ fixes from diagnostics\n Diagnostic intention menus now include a Fix action that opens inline chat and asks Copilot to\
  \ repair the issue. The action uses agent mode when it is available and ask mode otherwise, helping you move from a reported\
  \ problem to a proposed fix with fewer steps.\n\n\n More control over MCP server startup\n A new MCP setting lets you disable\
  \ automatic server startup for Copilot and Claude, giving you more control over when configured tools become active.\n\n\
  \n User experience enhancements\n This release makes everyday chat, account, and navigation workflows clearer:\n\n\n\n Account\
  \ controls : Signed-in Copilot accounts now have clearer labels, a simpler status display, better navigation for long lists,\
  \ and a Switch Account action.\n Chat discovery and sign-in : A one-time reminder helps new users find Chat , while the\
  \ sign-in page has a responsive layout, clearer headings, improved provider choices, a direct Copilot plans link, and cancellable\
  \ progress during browser authorization.\n Conversation navigation : Chat messages are grouped by turn, with controls for\
  \ moving quickly between turns.\n Message actions : User messages now include actions to copy or edit their content.\n Agent\
  \ guidance : The Copilot agent placeholder now highlights questions, edits, context, and commands.\n Migration flow : After\
  \ you accept a migration command, Go Back opens a Copilot home session even when you continue the local conversation.\n\n\
  \ Quality improvements\n This release improves reliability during language server startup, model and provider switching,\
  \ MCP configuration, customization refreshes, file changes, and worktree workflows. It also resolves interaction and display\
  \ issues in model management, tool-call details, working sets, and JetBrains IDE settings.\n\n\n Deprecation\n GitHub Copilot\
  \ has ended support for JetBrains IDE 2025.1. You now need JetBrains IDE 2025.2 or later to use the plugin.\n\n\n Try it\
  \ out\n We encourage you to try out the latest version of the GitHub Copilot plugin and share your feedback. Your input\
  \ is invaluable in helping us refine and improve the product.\n\n\n Share your feedback\n Your feedback drives improvements.\
  \ We’d love to hear about your experience in the following channels:\n\n\n\n In-product feedback: Use the feedback options\
  \ within your IDE.\n Feedback repository: Share your thoughts in the GitHub Copilot for JetBrains IDEs issues .\n\n\n The\
  \ post New controls and chat improvements in Copilot for JetBrains appeared first on The GitHub Blog ."
