  \ pull requests, settings, and agent sessions.\n\n\n GitHub Copilot app\n\n Set up Agent Merge directly from a pull request\
  \ to have Copilot merge it when it’s ready. It now stays enabled while required checks or rules are pending. You can also\

  \ pull requests have merged or closed, pin or unpin multiple sessions, and separate nested chats without losing the conversation.\
  \ My Work now supports more than ten saved custom views.\n Give Copilot guidance on which tool requests to approve without\
  \ asking you. Personal instructions for assisted approval are opt-in and apply to local sessions.\n\n Install the GitHub\
  \ Copilot app .\n\n\n GitHub Copilot CLI\n Manage your whole setup in one place. /settings now opens a unified dashboard\
  \ for your plugins, MCP servers, and more, and you can search across all of your settings.\n\n\n\n\n\n\n\n Install Copilot\
  \ CLI .\n\n\n GitHub Copilot in JetBrains\n Introducing a new way to use GitHub Copilot in JetBrains IDEs, with Copilot\
  \ now available in JetBrains Air. Track multiple agent sessions and run tasks locally in your JetBrains IDE or in the cloud\
  \ through Air Teams, using your existing Copilot subscription.\n\n\n Get started with Copilot in JetBrains Air .\n\n\n GitHub\
  \ Copilot in Xcode\n You can now work with GitHub Copilot directly in Xcode’s built-in coding assistant, bringing Copilot\
  \ into your native Xcode workflow. The integration is now in public preview, available starting with Xcode 27.3 beta.\n\n\
  \n Get started with Copilot in Xcode .\n\n\n GitHub Copilot in VS Code (1.145 release)\n\n Follow the conversation without\
  \ the clutter or, alternatively, choose to inspect every step. Experimental chat view modes let you collapse or expand reasoning\
  \ and tool calls without starting a new conversation.\n\n\n\n\n\n\n\n Check an agent’s work on another machine without leaving\
  \ VS Code. Preview remote apps and use interactive canvases in the Agents window, now in preview. Enable remote browser\
  \ support in settings, plus canvases to use that feature.\n\n\n Run recurring tasks on a schedule that fits your workflow.\
  \ Local automations now support cron expressions and custom agents from your workspace.\n\n\n Bring screenshots, mockups,\
  \ and other files into chat without moving them into your workspace. Choose them with Add Context > Files . Cloud sessions\
  \ only support images.\n Get back into long Copilot chats more smoothly. Past terminal output now renders as you expand\
  \ or reveal it instead of loading all at once.\n\n Explore everything that’s new in the full release notes .\n\n\n\n The\
  \ post GitHub Copilot weekly releases — November 2 appeared first on The GitHub Blog ."
