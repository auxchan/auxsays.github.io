{%- comment -%} THE SEARCH TITLE AND META DESCRIPTION OF A PATCH PAGE (GROWTH-1B), one include for both. WHY. Every patch page was titled " official update breakdown" and described as "Official update record captured from ", the writer's front-matter defaults that the site-wide SEO tag prints. A search result therefore never said what the page exists to say, whether to install the update, and 0 of the 96 Windows titles carried the KB people search for. NO SECOND VERDICT AUTHORITY. This include does not choose a verdict and does not re-run the decision ladder. It reads what the patch page itself just rendered: aux-base receives the finished aux-update markup as `content`, so the verdict is the text under the page's own "AUXSAYS verdict" eyebrow, the maturity is the page's own verdict-box class, the early-evidence qualifier is the page's own sentence, the recommendation is the page's own first sentence, and the identity is the page's own h1. A search result cannot claim a verdict the page does not print, because there is only one place the verdict is decided. LIVE WORDING NEEDS A CERTIFICATE AT RENDER TIME. The words "live consensus" appear only when the page's box reads live AND the shared maturity contract, which reads the deploy-time live eligibility projection, certifies the record now. A stored live claim the projection no longer lists reads as verified reports here exactly as it does on the page, so titles follow the corrected live set with no change to this file. HONEST STATES. INSUFFICIENT DATA prints "no verdict yet", never a decision word and never a claim that nothing is wrong; zero counted reports is stated as zero counted reports. A decision word is printed exactly as the page's verdict resolves (a legacy phrasing prints its canonical action). No safety claim is added beyond the page's own verdict and recommendation. SUPERSESSION IS NOT LABELLED. No record field names a replacement update, and a higher build or a later date alone does not prove one, so no title or description calls a page superseded. FAIL CLOSED. If the page markup does not carry exactly one verdict, one verdict box and one h1, or the verdict is outside the published vocabulary, this include emits nothing and the base layout falls back to the unchanged site-wide SEO tag. OUTPUT. Sets patch_search_emitted. When true it has emitted the same tags the site-wide SEO tag emits for a patch page (title, generator, og:title, og:locale, description, og:description, canonical, og:url, og:site_name, og:type, twitter:card, twitter:title, JSON-LD WebPage), with the canonical URL computed exactly as that tag computes it. The tag reacts to site settings this file does not read (twitter, facebook, webmaster verifications, a site logo or image); test_patch_decision_authority S24 pins that none is configured, so adding one fails a check instead of silently diverging.
