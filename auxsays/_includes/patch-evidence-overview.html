{%- comment -%} THE EVIDENCE OVERVIEW AND THE NEWER-RELEASE NOTE (G82-A, AUX-123). Prints one patch page's row of the deploy-time evidence overview projection (site.data.evidence_overview_projection, written by scripts/build_evidence_overview_projection.py from lib/evidence_overview.py). It decides nothing: every sentence below is the projection's, character for character, and qa_patch_records compares the projection with a recompute over the same tree before Jekyll builds anything. Input: include.record the patch page include.part 'overview' -- the count stated as a count, the source families and what the report list does and does not establish, printed at the foot of the community evidence card (it replaces the old count-only strength word); 'newer' -- a newer release (My Installed Versions' rule), then its caution (the vendor's documented known issue, or "Newer is not necessarily safer"), its own verdict exactly as the verdict projection prints it on its page or that AUXSAYS has not established one, and only then the links to its AUXSAYS page and its official notes. The caution comes before any link (AUX-123 A1). A row without a caution prints no note at all. 'next' -- the way forward on a page whose printed verdict is WAIT (G87, AUX-127): the projection's way-forward lines (archived, no better-supported alternative established, or no newer release on record), then any reviewed fixed_in line. Where a newer-release note is the way forward it has no lines of its own, so only a fixed_in line can print here. QA refuses a deploy whose WAIT page prints no next action (evidence_overview.has_next_action). FAIL CLOSED. No projection (a local render, a fresh checkout) or no row for this page: nothing is printed. The page keeps its verdict, its count and every source link; it only loses the overview. VENDOR TEXT. Fix lines print only when the projection carries them, and it carries them only for a source whose publication permission is on record. Today none is, so this prints the link only.
