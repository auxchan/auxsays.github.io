# Persistent Graph Read Model

Status: **LOCAL ADDITIVE DESIGN / NEVER PUBLISHED**

The local model implements `COMPUTE ONCE, READ MANY` with one immutable identity:

```text
worldId + graphSnapshotId + layoutVersion + topologyFingerprint
  canonical factors
  hierarchy placements
  typed relationships
  deterministic coordinates
  exact-ten child indexes
  coverage and gate state
```

Selection never creates factors, placements, relationships, or coordinates.
The browser derives only camera, LOD, emphasis, and inspector context.

The model distinguishes:

- `MASTER_DEFINED` Level-1 driver identities;
- `CANDIDATE` Level-2 research concepts;
- `TEST_FIXTURE` Level-3 renderer records;
- `HIERARCHY_TETHER` navigation relationships;
- `SYNTHETIC_INFLUENCE` stress relationships.

Every relationship is synthetic, test-only, never accepted, and never
publishable. Factual observations remain in the separate Workstream-1A
snapshot and are linked by navigation, not copied into this artifact.

PDI 1.0.0 need not change for local R&D. Before public activation, a reviewed
minor additive extension should publish only bounded graph summaries and
prevalidated focus/Trace references—not raw internal registries or an unbounded
whole-economy payload.
