# Development-only factor imagery

These images support the local `TEST_FIXTURE` structural-surface review. They
are not factual evidence for any relationship and are served only by the
loopback development server. The UI applies a CSS-only cyan/indigo grade,
reduced contrast, and edge fade; the source files remain unmodified.

Every node in this renderer must provide its own reviewed portrait metadata.
The TypeScript model and runtime validator reject new nodes that omit imagery,
and the local server exposes only its fixed media allowlist.
