# Glossary

- **OBS**: sourced observation.
- **CALC**: deterministic derived result.
- **FCST / SCEN**: forecast / scenario; currently locked.
- **Canonical factor**: one stable economic identity, independent of placement.
- **Placement**: one navigational occurrence of a factor in the hierarchy.
- **Hierarchy tether**: organization/drill-down link; never causal.
- **Structural relationship**: evidence-backed, versioned economic edge eligible only after acceptance.
- **Fixture**: synthetic development/test material; never publishable.
- **PDI**: Public Data Interface contract.
- **Valid time / knowledge time**: period described / time the system knew it.
- **Freshness**: source timeliness, not economic direction.
- **Gate A / Gate B**: Data Integrity gate (passed) / structural-proof gate (open).
- **Exact-ten**: exactly ten approved hierarchy children at complete branches; no filler.
- **LOD**: level of detail used to bound rendering and interaction.
