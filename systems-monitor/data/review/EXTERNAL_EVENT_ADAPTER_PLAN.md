# External Event Adapter Plan

Status: STATIC FRAMEWORK ONLY — ALL ADAPTERS DISABLED

The local engine can validate a candidate external event only when it has a versioned adapter identity, official native ID, valid/known times, bounded affected-node scope, evidence references, and provenance references.

Potential future official source families include NOAA/NWS weather alerts, EIA energy notices, Federal Register policy actions, BTS/FHWA/USCG transport notices, USDA supply notices, and formally reviewed trade authorities.

No speculative world-news scraper, social-media classifier, LLM classifier, or live external event has been activated. Candidate events cannot become factual relationships or connector impact without independent source, rights, taxonomy, relationship, and acceptance review.
